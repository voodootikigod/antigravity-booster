# Calibration Probes — 2026-06-11, agy v1.0.7, macOS (Darwin 25.5.0)

Method: `agy --print` with sentinel prompts (`Reply with exactly: PONG-<i>`),
success = exit 0 AND sentinel present in stdout. Single samples — noisy;
rankings indicative, not precise. Re-run with `agb probe`.

## Per-model round-trip latency (1 trivial prompt each)

| Model | ms |
|---|---|
| Claude Sonnet 4.6 (Thinking) | 2,623 |
| Claude Opus 4.6 (Thinking) | 3,018 |
| Gemini 3.5 Flash (High) | 4,021 |
| Gemini 3.5 Flash (Low) | 6,853 (3.0s in earlier run — variance high) |
| Gemini 3.1 Pro (High) | 8,548 |
| GPT-OSS 120B (Medium) | 9,690 |
| Gemini 3.5 Flash (Medium) | 10,212 |
| Gemini 3.1 Pro (Low) | 12,077 |

Surprise: **Claude models are the fastest** via agy on trivial prompts.
Latency ≠ throughput on long generations; treat as fixed-overhead estimate.

## Concurrency curve — Gemini 3.5 Flash (Low), single pool

| width | ok | fail | wall ms | median ms | max ms |
|---|---|---|---|---|---|
| 2 | 2 | 0 | 2,995 | 2,995 | 2,995 |
| 4 | 4 | 0 | 10,555 | 3,410 | 10,552 |
| 8 | 8 | 0 | 15,114 | 10,304 | 15,112 |
| 16 | 15 | 1 timeout | 336,149 | 8,464 | 336,144 |

Clear queueing/throttling past width 8: at 16, one call took 5.6 minutes and
one timed out. **Practical single-pool ceiling: 6** (default), 8 burst.

## Cross-pool concurrency — 4× Gemini Flash + 4× Claude Sonnet simultaneously

Wall: 14,107 ms, 8/8 ok. Claude calls: 2,951 / 3,482 / 3,610 / 10,701 ms —
essentially undisturbed by the concurrent Gemini load. **Pools throttle
independently** (consistent with the separate-quota-pool model).

→ Scheduler default: per-pool concurrency limits
`{gemini-flash: 6, gemini-pro: 4, claude: 4, gpt-oss: 2}` (pro/claude/gpt-oss
unprobed at width — conservative defaults, refine via `agb probe`).

## Behavioral findings

- Print mode performs file writes + shell commands non-interactively
  (allowlist in `~/.gemini/antigravity-cli/settings.json` governs).
- Exit code 0 even on `Error: timed out waiting for response` — must assert
  on output content.
- AGENTS.md + GEMINI.md in cwd are read in print mode (verified by magic-word
  recall); global skills from `~/.gemini/skills/` are visible to workers.

## Quota accounting note

Probes consumed ~60 agent requests across pools. Request-count quotas are the
binding constraint on lower plans — `agb` records request counts per run.
