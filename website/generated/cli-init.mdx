```text
agb init [repo]
```

Initialize a target repository for ADLC and agb (.adlc/config.json, specs/feature-template.md, .gitignore).

| Flag | Argument | Description |
| --- | --- | --- |
| --automations | — | scaffold Antigravity 2.0 declarative automations |
| --cloud | — | scaffold .agents/ zero-install cloud repo pack |
| --decision-provider | &lt;jev&#124;gemini-decisions&#124;kev&gt; | configure System-1 decision engine provider |
| --force | — | overwrite existing template/cloud files |
| --with-codegraph | — | add .codegraph/ to .gitignore, run codegraph init, enable in config |
