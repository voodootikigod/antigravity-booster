```text
agb shape <spec.md | id> [repo]
```

Deterministically pre-analyze a structured spec or brain plan for DAG validity, scope overlaps, and import coupling before agb plan.

| Flag | Argument | Description |
| --- | --- | --- |
| --analyze | — | pre-analyze spec |
| --json | — | emit JSON |
| --max-ticket-scope | &lt;n&gt; | warn above n files |
| --strict | — | fail on warnings |
| --sync-brain | — | sync to brain and .booster |
