```text
agb handoff <ticket-id> [repo]
```

Run interactive single-ticket ADLC P5+P6 verification, cross-model prosecution, and handoff dossier.

| Flag | Argument | Description |
| --- | --- | --- |
| --autocommit | — | stage and commit dirty worktree |
| --base | &lt;ref&gt; | git base ref |
| --browser-url | &lt;url&gt; | loopback preview URL |
| --build-cmd | &lt;cmd&gt; | build command |
| --html | &lt;file&gt; | write HTML P6 cockpit |
| --json | — | emit JSON |
| --no-manifest | — | skip gate-manifest recording |
| --no-prosecute | — | skip cross-model prosecutor |
| --prompt-only | — | emit prosecutor prompt without agy |
| --require-prosecutor | — | fail closed if agy unavailable |
| --skip-browser | — | skip browser prosecutor |
| --skip-hollow | — | skip hollow-test |
| --test-cmd | &lt;cmd&gt; | test command |
| --worktree | &lt;dir&gt; | candidate worktree |
| -id | — | — |
