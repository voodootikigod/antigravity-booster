```text
agb status [repo]
```

Render the live dashboard for a repo's current run.

| Flag | Argument | Description |
| --- | --- | --- |
| --compact | — | compact rows |
| --follow | — | follow logs |
| --interval | &lt;ms&gt; | poll interval |
| --tui | — | render TUI snapshot |
| --watch | — | watch mode |
| -w | — | watch mode |
