```text
agb run <plan.json>
```

Execute a ticket DAG (build → gate → prosecute → merge).

| Flag | Argument | Description |
| --- | --- | --- |
| --driver | &lt;local&#124;remote-sdk&gt; | execution driver |
| --dry-run | — | preview remote-sdk waves without spawning |
| --reset-rescue | — | clear rescue locks |
| --resume | — | skip already-merged tickets |
| -c | &lt;n&gt; | cap concurrent workers |
