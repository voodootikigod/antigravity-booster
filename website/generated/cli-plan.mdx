```text
agb plan <id | spec.md> [repo]
```

Compile an Antigravity brain plan or spec file into plan.json.

Pipeline: convert → validate → overlap/coldstart/parallax gates with feedback loop → advisory premortem.

| Flag | Argument | Description |
| --- | --- | --- |
| --decompose | — | split wide tickets |
| --emit-workflow | &lt;file.py&gt; | emit native run_workflow script |
| --force | — | overwrite existing |
| --max-ticket-scope | &lt;n&gt; | max files per ticket |
| --no-coldstart | — | skip coldstart |
| --no-fast-path | — | force LLM conversion |
| --no-parallax | — | skip parallax |
| --no-premortem | — | skip premortem |
| --out | &lt;file&gt; | output plan path |
