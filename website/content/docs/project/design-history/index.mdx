<Callout type="info" title="Historical, superseded">
Nothing in this section describes current behavior. Use the rest of the docs for that.
</Callout>

This section keeps the research notes and design specs that shaped `agb`: roadmaps written against specific agy releases, probes of the agy CLI and the Antigravity desktop app, the Linux sandbox evaluation, and a summary of the native plugin installation spec. The research notes are copied from `docs/archive/research/` with their text kept as written. Each page begins with a note listing what has changed since.

These pages are left out of site search, `llms.txt` and `llms-full.txt` so they never appear as answers about current behavior. Where a page disagrees with the current docs, the current docs win. They come from the code at v1.0.0.
