`agb doctor` checks your environment and prints one row per check:

```text
<name>                    | PASS   | <detail>                       | <fix>
```

The level is `PASS`, `WARN` or `FAIL`. Doctor exits `1` if any check is `FAIL`, or if a check itself throws (it then prints `Error check failed: <reason>` in place of a table row), and `0` otherwise. Warnings never change the exit code ([lib/doctor.mjs](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/doctor.mjs#L1229-L1265)).

```sh
agb doctor
```

### adlc-antigravity plugin

Doctor evaluates the staged companion plugin under `~/.gemini/config/plugins/adlc-antigravity`. A failing state reports one of these values as its detail ([L151-L157](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/doctor.mjs#L151-L157)):

| Detail | Fix text |
| --- | --- |
| `not-installed` | ``Run `agb bootstrap` to install the bundled plugin.`` |
| `corrupt-manifest` | ``Run `agb bootstrap --force-reinstall`.`` |
| `outdated-plugin` | ``Run `agb bootstrap` to upgrade to the bundled plugin.`` |
| `corrupt-tree` | ``Run `agb bootstrap` to reinstall the pristine plugin.`` |
| `incompatible-contract` | ``Run `agb bootstrap --force-reinstall` to install the bundled plugin.`` |

When the plugin does not declare its contract (a "tolerant" state), doctor warns with `Upgrade the plugin to one that declares adlcContract 1.` ([L166](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/doctor.mjs#L166)).

### adlc CLI

Doctor looks for `@adlc/cli` (`node_modules/.bin/adlc` in the current directory, or the resolved binary) and reports one of the following ([C31](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/doctor.mjs#L325)):

| Situation | Level | Fix text |
| --- | --- | --- |
| Package manifest authentication failed | fail | ``Repair or reinstall @adlc/cli (>= <MIN_ADLC_CLI_VERSION>).`` |
| Not found (detail `not found (will be installed by bootstrap)`) | warn | ``Run `npm install @adlc/cli` or `npx agb bootstrap`.`` |
| Version below the minimum | fail | ``Upgrade @adlc/cli to >= <MIN_ADLC_CLI_VERSION>.`` |
| Execution failed | fail | ``Ensure @adlc/cli executable at <bin> has execute permissions and a valid Node interpreter.`` |
| Binary resolved but could not be probed, with no path to report | warn | `adlc CLI is optional but recommended. Install it if you want local ADLC gate execution.` |

Install `@adlc/cli` locally (`npm install @adlc/cli`), not globally. Contributors to this repository get it through `npm ci`.

### Sandbox

Gates run inside a kernel sandbox, and doctor checks the one for your platform ([`checkSandbox`](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/doctor.mjs#L1086)). `AGB_SANDBOX_GATES=0` bypasses it and reports `bypassed via env`.

| Platform | Detail | Level | Fix text |
| --- | --- | --- | --- |
| macOS | `sandbox-exec available` | pass | — |
| macOS | `sandbox-exec missing or unusable` | fail | `macOS sandbox-exec is missing or unusable. Set AGB_SANDBOX_GATES=0 to bypass.` |
| Linux | `bwrap available` | pass | — |
| Linux (`bwrap_unusable`) | `bwrap unusable (namespace probe failed)` | fail | `Linux bubblewrap (bwrap) is installed but unusable (user namespaces may be disabled or restricted in container). Enable unprivileged user namespaces or set AGB_SANDBOX_GATES=0 to bypass.` |
| Linux (`bwrap_missing`) | `bwrap missing` | fail | `Linux bubblewrap (bwrap) is missing. apt install bubblewrap or set AGB_SANDBOX_GATES=0 to bypass.` |
| Windows | `bypassed via verified HMAC attestation` | pass | — |
| Windows | `attestation rejected: <reason>` | fail | `Repair or update sandboxBypassAttestation in .adlc/config.json.` |
| Windows | `malformed config: <error>` | fail | `Repair .adlc/config.json.` |
| Other (and Windows without an attestation) | `unsupported platform: <platform>` | fail | `Sandbox is only supported on macOS, Linux, and Windows. Set AGB_SANDBOX_GATES=0 to bypass.` |

On Linux, the probe classifies a failure by `kind` ([lib/doctor.mjs](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/doctor.mjs#L1060-L1067)):

- **`bwrap_missing`**: `bwrap` is not installed. Fallback mechanisms (`systemd-run`, `unshare`) are rejected because they provide insufficient filesystem isolation.
- **`bwrap_unusable`**: `bwrap` is installed but its usability probe failed. User namespaces are usually disabled (for example `sysctl kernel.unprivileged_userns_clone=0`) or restricted inside a container.

The other probe kinds are `sandbox_exec_unavailable` (macOS), `powershell_missing` (Windows), `unsupported_platform` and `mock_unavailable` (tests only).

<Callout type="warn">
  `AGB_SANDBOX_GATES=0` turns off sandboxing of gate commands entirely. Use it only on machines where you accept running gate commands unsandboxed. See [Gates and sandboxing](/docs/concepts/gates-and-sandboxing).
</Callout>

### Ticket store

| Detail | Level | Fix text |
| --- | --- | --- |
| `both legacy and directory stores` | fail | ``The plugin fails closed when both exist. Run `adlc ticket store migrate` (or remove .adlc/tickets.json).`` |
| `orphaned directory store (no .store.json)` | warn | ``Likely an interrupted projection — the next `agb plan` recovers it, or run `adlc ticket doctor`.`` |
| `none (created on first projection)` | pass | — |
| `store corruption: ...` | fail | ``Run `adlc ticket doctor` to diagnose and repair ticket store issues.`` |

The conflict is detected by `detectTicketStoreBackend`, which returns `'both'` when `.adlc/tickets/` and the legacy `.adlc/tickets.json` both exist ([lib/adlc-bridge.mjs](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/adlc-bridge.mjs#L176)). The plugin treats that state as fail-closed, so resolve it before running anything.
