Each folder under [`skills/`](https://github.com/voodootikigod/antigravity-booster/blob/main/skills) is one skill with a `SKILL.md` and optional `scripts/`. The table is generated from each `SKILL.md` frontmatter and its `scripts/` listing.

## Notes

- Every skill runs in Claude Code, Codex and agy. `skills/<name>/` is the only copy to edit; `npm run skills:sync` mirrors it into `.claude/skills/` (Claude Code) and `.agents/skills/` (Codex and agy), and `npm test` fails if a mirror drifts.
- **User-facing orchestration skills (`agb`, `agb-bootstrap`, `agb-doctor`, `agb-migrate`, `agb-plan`, `agb-review`, `agb-run`, `agb-sidecar`)**: Native Antigravity plugins (`plugin.json` at root) load skills from `skills/<name>/SKILL.md` rather than `commands/*.md`. Shipping these eight skills under `skills/` ensures native `agy` plugin installations expose both the top-level `/agb <description>` natural-language router (`skills/agb/SKILL.md`) and all seven `/agb-*` subcommand workflows via progressive skill disclosure and slash commands.
- **modernize** audits this plugin against the latest agy and ADLC releases and produces a modernization ticket DAG; its probe logic is in `scripts/audit.mjs` ([modernize frontmatter](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/skills/modernize/SKILL.md#L1-L8)).
- **release** is marked internal: it is the maintainers' release procedure for this repository, not something plugin users run ([release frontmatter](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/skills/release/SKILL.md#L1-L9)). The process is documented in [Releasing](/docs/project/releasing).
- **release-audit** is marked internal: it audits the repository across every surface and computes a release readiness verdict before cutting a release ([release-audit frontmatter](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/skills/release-audit/SKILL.md#L1-L9)). The process is documented in [Releasing](/docs/project/releasing).
- When staging a clean Marketplace bundle (`npm run plugin:validate` / `scripts/stage-marketplace-plugin.mjs`), the three internal maintainer skills (`modernize`, `release`, `release-audit`) are filtered out so end users receive only the eight user-facing `agb` and `agb-*` skills.

The ADLC doctrine skills (spec, ticket, prosecute and others) are not part of this plugin: they come from the `adlc-antigravity` companion plugin that [`agb bootstrap`](/docs/reference/cli/bootstrap) installs.
