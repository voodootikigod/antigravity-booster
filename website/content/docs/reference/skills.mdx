Each folder under [`skills/`](https://github.com/voodootikigod/antigravity-booster/blob/main/skills) is one skill with a `SKILL.md` and optional `scripts/`. The table is generated from each `SKILL.md` frontmatter and its `scripts/` listing.

## Notes

- **User-facing orchestration skills (`agb`, `agb-bootstrap`, `agb-doctor`, `agb-migrate`, `agb-plan`, `agb-review`, `agb-run`, `agb-sidecar`)**: Root [`skills/`](https://github.com/voodootikigod/antigravity-booster/blob/main/skills) holds strictly the eight user-facing plugin skills (`agb` umbrella router plus the seven `agb-*` subcommands). Native Antigravity plugins (`plugin.json` at root) load skills from `skills/<name>/SKILL.md` rather than `commands/*.md`. Shipping only these eight skills under `skills/` ensures native `agy` plugin installations expose `/agb <description>` and `/agb-*` workflows without polluting user workspaces with internal repository maintainer skills.
- **Internal repository maintainer skills (`modernize`, `release`, `release-audit`)**: Stored outside root `skills/` under `maintainer-skills/` and mirrored into `.claude/skills/` (Claude Code) and `.agents/skills/` (Codex and `agy` workspace scope) by `npm run skills:sync` (`npm test` fails if a mirror drifts). Because they live outside `skills/` and are excluded from `package.json` `files` and `copyPluginTree`, they are never exposed when users install the plugin. See [Releasing](/docs/project/releasing).

The ADLC doctrine skills (spec, ticket, prosecute and others) are not part of this plugin: they come from the `adlc-antigravity` companion plugin that [`agb bootstrap`](/docs/reference/cli/bootstrap) installs.
