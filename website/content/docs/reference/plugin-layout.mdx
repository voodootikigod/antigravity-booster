## How the pieces connect

- **Marketplace metadata & brand icon**: `plugin.json` declares `displayName`, a search-optimized `description`, `logo` (`assets/logo.svg`, a `256x256` 1:1 vector badge with a `10.9%` outer margin for light and dark themes), `suggestedPrompts` (3 clickable starter prompts), `homepage`, and `repository`.
- **Always-on session rule (`rules/AGENTS.md`)**: Native Antigravity plugins load session rules exclusively from `rules/`. `rules/AGENTS.md` teaches Antigravity in enabled sessions when to reach for `mcp__agb__*` tools (`agb_doctor`, `agb_plan`, `agb_run`, `agb_review`) and `/agb-*` skills.
- **Native skills (`skills/agb-*/SKILL.md`)**: In `agy 1.4.x`, native plugins load skills from `skills/<name>/SKILL.md` (`commands/` is only converted when importing foreign Claude Code or Gemini CLI extensions). All 7 user-facing `/agb-*` workflows (`agb-bootstrap`, `agb-doctor`, `agb-migrate`, `agb-plan`, `agb-review`, `agb-run`, `agb-sidecar`) are shipped under `skills/` alongside `commands/`. `scripts/stage-marketplace-plugin.mjs` (`npm run plugin:validate`) stages a clean Marketplace bundle that excludes contributor-only root files and maintainer-only skills and verifies `agy plugin validate --strict --json` passes with 0 errors, 0 warnings, and 0 notes.
- **PreToolUse hook**: `hooks.json` runs `bin/hook-runner.sh` with the bundled policy guard `dist/hooks/pre-tool-use.bundle.mjs` on every tool call. The runner fails closed: an unparseable payload or a headless worker gets a deny decision ([fail-safe decisions](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/bin/hook-runner.sh#L205-L218)). See [Rail enforcement](/docs/concepts/rail-enforcement) and [Policy guard](/docs/internals/policy-guard).
- **MCP server**: `mcp_config.json` starts `dist/mcp-server.mjs` through `bin/node-launcher.sh`, which locates a usable Node runtime. See [MCP tools](/docs/reference/mcp-tools).
- **Vendored ADLC**: `vendor/adlc` is the pinned ADLC CLI the bundled build uses exclusively, and `vendor/cache` holds the pristine npm tarball of the companion plugin. See [Plugin and migration](/docs/internals/plugin-and-migration) and [Build and bundle](/docs/internals/build-and-bundle).
- **Sidecar**: `sidecars/` holds the dashboard server and its static UI, started by [`agb sidecar`](/docs/reference/cli/sidecar).

The terminal shim `~/.local/bin/agb` is written by bootstrap, not shipped in the plugin directory.
