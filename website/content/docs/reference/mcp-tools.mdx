The plugin registers an MCP server named `agb` (see [Plugin layout](/docs/reference/plugin-layout)). It speaks JSON-RPC over stdio (`tools`, `resources`, and Antigravity `ui://` MCP App resources) and exposes **15 tools**: 10 CLI-backed workflow tools that invoke the matching [CLI](/docs/reference/cli) subcommand, plus 5 in-process UI/control/sign-off tools (`agb_flight_deck`, `agb_mission_control`, `agb_plan_viewer`, `agb_control`, `agb_accept`) paired with 6 interactive `ui://agb/*.html` resources.

## Server

The server answers `initialize` with protocol version `2024-11-05` and `serverInfo.name` `antigravity-booster-mcp`. `serverInfo.version` is read from the plugin's `package.json`, the same source `agb --version` uses (v1.0.0 hard-coded `0.7.0` instead: [C6](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/mcp/server.mjs#L153-L156)).

Child processes inherit the ambient environment from the host agent harness. Unknown tools return JSON-RPC error `-32602`, unknown methods `-32601`.

## Tools

The list below is generated from the `TOOLS` array in `mcp/server.mjs`.

<Callout type="info" title="agb_run concurrency cap">The MCP `agb_run` tool accepts `plan` and an optional positive integer `concurrency` parameter, which is validated and forwarded as `-c <n>` to `agb run` to cap total concurrent workers (v1.0.0 previously forwarded an unsupported flag that `agb run` ignored: [C33](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/mcp/server.mjs#L185-L187)). Per-pool runtime concurrency is also governed by the plan's `caps` field (while `concurrencyCap` is an advisory fan-out forecast written by `adlc merge-forecast`).</Callout>

## Mapping to the CLI

| Tool | Runs / Mode |
| --- | --- |
| `agb_shape` | `agb shape <spec> [repo] --json` plus `--sync-brain`, `--max-ticket-scope`, `--strict` |
| `agb_plan` | `agb plan <spec> <repo>` plus `--out`, `--emit-workflow` (`emitWorkflow`), `--estimate`, `--force`, `--decompose`, `--max-ticket-scope`, `--no-fast-path`, `--no-coldstart`, `--no-parallax`, `--no-premortem` |
| `agb_distill` | `agb distill <repo> --json` plus `--apply`, `--compile-checks` (`compileChecks`) |
| `agb_run` | `agb run <plan>` plus `-c <n>` (`concurrency`), `--resume`, `--reset-rescue` (`resetRescue`) |
| `agb_preflight` | `agb preflight <plan>` plus `--no-coldstart` |
| `agb_status` | `agb status <repo>` |
| `agb_doctor` | `agb doctor [repo]` plus `--fix` |
| `agb_init` | `agb init <repo>` |
| `agb_review` | `agb review <repo> [ref]` plus `--plan`, `--loop`, `--five-lens`, `--no-arbiter` |
| `agb_holdout` | `agb holdout <list\|run\|clean> [repo]` plus `--ticket` (`ticketId`), `--run-id` (`runId`) |
| `agb_control` | In-process `control.sock` IPC / diff / stream telemetry (`action`, `repo`, `ticketId`, `lines`) |
| `agb_accept` | In-process P6 sign-off dossier & hunk verdict persistence (`repo`, `base`, `verdicts`, `saveVerdicts`, `ui://agb/accept-workbench.html`) |
| `agb_flight_deck` | In-process UI resource (`ui://agb/flight-deck.html`) + live `control.sock` snapshot (`repo`) |
| `agb_mission_control` | In-process UI resource (`ui://agb/mission-control.html`) + Factory Economics Ledger & quota telemetry (`repo`) |
| `agb_plan_viewer` | In-process UI resource (`ui://agb/plan-viewer.html`) for inspecting and saving `.agbplan` / `plan.json` (`path`, `repo`) |

Evidence: [tool dispatch](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/mcp/server.mjs#L178-L196). The server resolves the CLI to the sibling `dist/agb.mjs` in the bundled plugin, `bin/agb.mjs` in a source checkout, or `agb` on `PATH` ([resolveAgbEntry](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/mcp/server.mjs#L19-L23)). See [Headless and MCP](/docs/guides/headless-and-mcp).
