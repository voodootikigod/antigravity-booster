`agb accept` inspects repository changes relative to `<base>`, detects external caller blast radius across the workspace, and renders the interactive P6 hunk sign-off workflow (or writes a Markdown review dossier via `--markdown <file>`).

## Arguments and flags

- `[repo]` targets the repository directory (defaults to `.`).
- `--base <ref>` specifies the base git ref to diff against (defaults to `HEAD`).
- `--json` emits the structured hunk dossier, external caller list, and recorded verdicts to stdout.
- `--markdown <file>` exports the P6 acceptance dossier as Markdown to the specified file.
- `--html <file>` exports a self-contained interactive P6 Sign-Off Cockpit HTML artifact (suitable for Web Standalone and Remote Agent Brain previews).

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Inspection completed (and verdicts saved cleanly if requested). |
| `1` | Invalid flags, missing repository, or internal error. |
