`agb doctor` runs the environment checks and prints each result with a suggested fix. It accepts an optional `[repo]` path (defaulting to the current directory) and an optional `--fix` flag.

## Behavior

The exit code is whatever `runDoctor` returns. Passing `--fix` automatically repairs a missing `.adlc` store, `.gitignore` entries, or companion plugin (only scaffolding repository files when the target is an existing git or ADLC repository). Checks include the agy version floor `1.2.6` (recommended `1.5.9`), agy authentication, the sandbox, hook audit-log directory, the ADLC CLI, the staged plugin, the model catalog, and the ticket store. Every check id and its fix text is documented in [Verify your install](/docs/getting-started/verify).
