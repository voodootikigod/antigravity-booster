`agb gate-ticket` runs deterministic ADLC P5 prosecution for a single ticket shard in `.adlc/tickets/` without requiring an `agy` binary: verifying scope confinement, physical symlink containment, `adlc rails-guard`, sandboxed build/test gates, `.adlc/learned-checks.json` invariants, optional `adlc hollow-test`, and `adlc gate-manifest` recording.

## Arguments and flags

- `<ticket-id>` specifies the ticket ID in `.adlc/tickets/` (for example, `T-W1-1`).
- `[repo]` targets the repository directory (defaults to `.`).
- `--base <ref>` specifies the git base ref to diff against (defaults to `HEAD~1`).
- `--worktree <dir>` evaluates candidate changes inside an isolated `.worktrees/agb-<id>` checkout.
- `--test-cmd <cmd>` overrides the test command (defaults to `npm test`).
- `--build-cmd <cmd>` runs an optional build gate command before the test command.
- `--browser-url <url>` supplies a loopback preview URL (`http://127.0.0.1:<port>`) for `browserGate` route checks.
- `--skip-hollow` skips `adlc hollow-test` mutation testing.
- `--skip-browser` skips the `browserGate` visual/HTTP check.
- `--autocommit` stages and commits dirty candidate changes in the target worktree before diffing.
- `--no-manifest` skips recording advisory audit entries in `.adlc/manifest.jsonl`.
- `--json` emits the structured verification report to stdout.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | All P5 gates passed for `<ticket-id>`. |
| `2` | Scope leak, rail violation, empty diff, test failure, learned-check failure, or `hollow-test` survivor. |
| `1` | Invalid flags, missing `<ticket-id>`, or internal error. |
