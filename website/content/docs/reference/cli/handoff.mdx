`agb handoff` executes the complete single-ticket ADLC P5 and P6 sign-off pipeline for interactive sessions across Antigravity IDE, the 7 IDE Extensions, `agy` CLI, and Cloud VMs: running `agb gate-ticket` (scope, `adlc rails-guard`, sandboxed build/tests, `.adlc/learned-checks.json`, `browserGate`, and `adlc hollow-test`), invoking single-diff cross-model `prosecute()` when `agy` and quota are available (or emitting the structured prosecutor prompt in `--prompt-only` / zero-`agy` fallback mode), and rendering a P6 sign-off dossier.

## Arguments and flags

- `<ticket-id>` specifies the ticket ID in `.adlc/tickets/` (for example, `T-W2-1`).
- `[repo]` targets the repository directory (defaults to `.`).
- `--base <ref>` specifies the git base ref to diff against (defaults to `HEAD`).
- `--worktree <dir>` evaluates candidate changes inside an isolated `.worktrees/agb-<id>` checkout.
- `--test-cmd <cmd>` overrides the test command (defaults to `npm test`).
- `--build-cmd <cmd>` runs an optional build gate command before the test command.
- `--browser-url <url>` supplies a loopback preview URL (`http://127.0.0.1:<port>`) for `browserGate` route checks.
- `--html <file>` writes a self-contained HTML P6 acceptance cockpit including any captured `browserGate` screenshots.
- `--skip-hollow` skips `adlc hollow-test` mutation testing.
- `--skip-browser` skips the `browserGate` visual/HTTP check.
- `--autocommit` stages and commits dirty candidate changes in the target worktree before diffing.
- `--no-prosecute` skips cross-model prosecution and finishes after `gate-ticket` + P6 dossier assembly.
- `--prompt-only` emits the structured cross-model prosecutor prompt without spawning `agy`.
- `--require-prosecutor` fails closed (exit `2`) if `agy` or model quota is unavailable instead of degrading to prompt-only output.
- `--no-manifest` skips recording advisory audit entries in `.adlc/manifest.jsonl`.
- `--json` emits the structured handoff report to stdout.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | All P5 gates and prosecution passed (or degraded cleanly to prompt-only handoff when `--require-prosecutor` is not set). |
| `2` | Gate failure (`gate-ticket`), prosecutor `iterate`/`escalate` verdict, or unavailable `agy` with `--require-prosecutor`. |
| `1` | Invalid flags, missing `<ticket-id>`, or internal error. |
