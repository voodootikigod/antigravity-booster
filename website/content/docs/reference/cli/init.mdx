---

`agb init [repo]` bootstraps a target repository for ADLC and `agb`: it creates `.adlc/tickets/` and `.adlc/config.json` (in `unsigned-fallback` mode without setting human-only attestation flags), scaffolds `specs/feature-template.md` when absent, and appends `.booster/` and `.worktrees/` to `.gitignore`.

## Arguments

- `repo` is optional and defaults to the current directory (`.`). Outputs `{ ok, repo, created, skipped }` as JSON.
