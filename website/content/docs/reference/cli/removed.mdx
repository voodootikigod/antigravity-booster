## agb tui

<include>../../../../generated/cli-tui.mdx</include>

`agb tui` remains removed and exits `1` with a pointer to [`agb sidecar`](/docs/reference/cli/sidecar) (web sidecar) and [`agb watch`](/docs/reference/cli/watch) (interactive terminal TUI dashboard; see the v1.0.0 [tui handler](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/bin/agb.mjs#L281-L283)).

## The status UI flag

Passing `--ui` to `agb status` exits `1` with a pointer to `agb sidecar` and `agb watch` (use `agb status --tui` for a one-shot TUI snapshot or `agb watch` for the live dashboard; see [flag removal](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/bin/agb.mjs#L269-L272)).
