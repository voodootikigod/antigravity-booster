title: "agb brains"
description: "List Antigravity plan artifacts from the GUI and agy sessions."
---

`agb brains` lists the Antigravity plan artifacts ("brains") that [`agb plan`](/docs/reference/cli/plan) can compile, one per line: id, last-modified date and title ([brains output](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/bin/agb.mjs#L244-L245)).

The brain directory defaults to `~/.gemini/antigravity/brain` and can be changed with `AGB_BRAIN_DIR` (see [Environment](/docs/reference/environment)).
