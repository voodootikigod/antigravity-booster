`agb review` prosecutes a diff or a plan specification with a read-only fleet of model "lenses" using single-pass review by default (`--thorough` or `--dry-rounds <n>` for multi-dry convergence).

## Arguments and flags

- `repo` is optional and defaults to the current directory ([C11](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/bin/agb.mjs#L147)).
- `ref` is optional: a range such as `main...HEAD` or a SHA range. Without it, uncommitted changes are reviewed against `HEAD`.
- `--plan <spec.md>` runs the 5-lens Plan Adversarial Review Loop (ARL) against a Markdown specification instead of a git diff.
- `--loop` runs iterative ARL up to 3 rounds.
- `--five-lens` (alias `--5-lens`) uses the 5-lens Code ARL (Correctness/Red-Team, Simplicity, Security, Evidence Runner, Anti-Slop) instead of the default 4-lens fleet.
- `--thorough` enables multi-dry stochastic convergence (`dryRounds=2`, `maxRounds=3`); `--dry-rounds <n>` sets consecutive dry rounds required.
- `--delta <base-ref>` and `--prior-findings <path>` review only the fix-round delta while embedding prior open findings (default `.review/last-findings.json`).
- `--seams-only` and `--plan-file <plan.json>` audit only cross-ticket integration seams when every merged commit passed per-ticket System-2 prosecution.
- `--no-codegraph` disables CodeGraph (`.codegraph/`) context slicing and blast-radius scoring.
- `--no-decision-engine` disables System-1 Decision Engine lens gating and typed Arbiter triage.
- `--no-arbiter` skips neutral arbiter triage.

An empty diff exits 0 with nothing to review. Quota telemetry must be available.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | Empty diff (when not `--plan`), or converged with `gateVerdict === "SHIP"` and no `critical` / `high` / escalated findings. |
| 2 | `critical` / `high` / escalated / `blast_radius` findings remain, `--plan` `ok` is `false`, `gateVerdict !== "SHIP"` (including `> 180k` payload truncation), or the fleet did not converge ([review exit](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/bin/agb.mjs#L160-L163)). |
| 1 | Quota telemetry unavailable, usage error (`missing --plan` argument), or an internal error. |
