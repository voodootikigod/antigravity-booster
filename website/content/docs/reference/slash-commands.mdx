The plugin ships 16 slash commands — one per Markdown file in [`commands/`](https://github.com/voodootikigod/antigravity-booster/blob/main/commands) (`/agb`, 12 `/agb-*` subcommands, plus `/code-review`, `/plan-review`, and `/implement-and-review`) — and ships all 17 user-facing native Antigravity plugin skills (those 16 plus `adversarial-review`) under [`skills/`](https://github.com/voodootikigod/antigravity-booster/blob/main/skills) (`skills/<name>/SKILL.md`) so both native `agy` plugins and imported Claude Code / Gemini CLI extensions expose `/agb <description>`, `/agb-*`, and the adversarial review workflows. Typing `/agb <description>` routes any natural-language task or subcommand (`shape`, `plan`, `run`, `review`, `doctor`, `bootstrap`, `migrate`, `sidecar`, `status`, `watch`, `preflight`, `init`, `sync-models`, `validate`, `pool`, `brains`, `sweep`) to the right `agb` workflow, while each `/agb-*` command is a direct wrapper around the [CLI](/docs/reference/cli) command of the same name. The table is generated from each file's frontmatter and its H1 usage line.

## How they run

- The agent runs `~/.local/bin/agb <command> ...` from the user's workspace, passing arguments through unchanged, and reports the output and exit code (0 pass, 2 gate failure or findings, 1 usage or internal error) ([agb-run instructions](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/commands/agb-run.md#L12-L20)).
- If the shim is missing, the agent stops and asks the user to bootstrap once from a terminal ([missing shim](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/commands/agb-run.md#L22-L28)). See [Bootstrap](/docs/getting-started/bootstrap).
- When the `agb` MCP server is connected, the agent may call the matching MCP tool instead (see [MCP tools](/docs/reference/mcp-tools)).

Slash commands run in the interactive session; see [Headless and MCP](/docs/guides/headless-and-mcp) for print mode.
