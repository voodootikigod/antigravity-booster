This map is generated by statically reading the `export` declarations of every module (named exports, `export { }` lists and re-exports). It replaces the hand-written module map in the old architecture document, which named classes and functions that no longer exist ([C26](https://github.com/voodootikigod/antigravity-booster/blob/v1.0.0/lib/pools.mjs#L1336): the pool manager is `PoolSet`).

Entry points (`bin/agb.mjs`, `hooks/pre-tool-use.mjs`, and the sidecar launcher) have no exports. For how the modules fit together see [Architecture](/docs/internals/architecture).
